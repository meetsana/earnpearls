# EarnPearls Phase 0

Phase 0 is the controlled planning and approval stage required by the EarnPearls
Master Product Constitution before implementation may begin.

## Current gate

- EP-P0-01 v3 status: **APPROVED REQUIREMENTS BASELINE — PHASE 0 DERIVATION ONLY**
- EP-P0-02: **IN PROGRESS — BUSINESS BLUEPRINT V1**
- EP-P0-03 through EP-P0-13: **BLOCKED BY THE PRECEDING DOCUMENT GATE**
- Phase 1 implementation: **BLOCKED**
- Existing UI code: exploratory prototype only

The approved EP-P0-01 baseline contains open ODR, DDR, and EFE records. Approval
of the register confirms traceability; it does not resolve those records.

## Controlled sequence

1. EP-P0-01 — Constitution Compliance Register
2. EP-P0-02 — Business Blueprint Version 1
3. EP-P0-03 — Business Blueprint Self-Review & Version 2
4. EP-P0-04 — Product Blueprint Version 1
5. EP-P0-05 — Product Blueprint Self-Review & Version 2
6. EP-P0-06 — Technical Architecture Options & ADRs
7. EP-P0-07 — Authentication & Authorization Design
8. EP-P0-08 — Database Architecture
9. EP-P0-09 — API & Integration Architecture
10. EP-P0-10 — Provider Visibility Policy
11. EP-P0-11 — Security Architecture
12. EP-P0-12 — Infrastructure & DevOps Plan
13. EP-P0-13 — Implementation Roadmap

Each document advances only after the preceding document is complete and passes
independent review. Frontend implementation remains blocked until EP-P0-04 and
EP-P0-05 establish and approve the Product Blueprint and UI/UX baseline.
